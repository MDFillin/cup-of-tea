# The Cup of Tea для Android TV

Тот же клиент, что и для Windows, только под телевизор и пульт: подписки, ссылки, полные конфиги xray из подписки,
маршруты, обход блокировок, автовыбор, пинг, обновление из программы. Kotlin + Compose for TV, xray 26.10.21 внутри
приложения. Android 7+ (API 24), архитектуры arm64-v8a, armeabi-v7a (многие приставки 32-битные даже на 64-битном
процессоре) и x86_64 (эмулятор).

## Устройство
- **Одно ядро в процессе.** xray собирается в AAR через gomobile (`core-go/`, обёртка `libcup`): запуск по конфигу,
  TUN от `VpnService` прямо во вход `tun` xray (`xray.tun.fd`), без sing-box и промежуточного SOCKS. Сама программа
  исключена из VPN — соединения xray с сервером идут мимо туннеля.
- **Проверки без открытых портов.** Пинг, внешний IP и сторож связи идут через само ядро (`core.Dial`, выход по тегу):
  открытый прокси на 127.0.0.1 видят другие приложения, и некоторые по нему узнают VPN.
- **`core/`** — логика без Android (порт `src/PVpn.Core` с тестами): разбор ссылок, подписки с заголовками панели и HWID,
  сборщик конфигов xray, полные конфиги из подписки, автовыбор, профили маршрутизации, обход блокировок, DNS,
  пинг, сторож, базы geo, обновления.
- **`app/`** — служба VPN, зашифрованное хранилище (AES-GCM, ключ в Android Keystore), интерфейс под пульт,
  страница для телефона.

## Отличия от Windows
- Только VPN (режима прокси нет). Kill switch — системный «Постоянный VPN» с блокировкой без VPN
  (`adb shell settings put secure always_on_vpn_app io.github.mdfillin.cupoftea.tv` и `always_on_vpn_lockdown 1`);
  при перезапуске ядра туннель не закрывается, поэтому в эти секунды мимо VPN ничего не уходит.
- Локальная сеть (DLNA, трансляция экрана, NAS) и IP текущего сервера идут мимо туннеля.
- Раздельное туннелирование — по приложениям («мимо VPN» или «только через VPN»); сайты — профилями маршрутизации.
- Обход блокировок — три готовых варианта (Выкл / Стандарт / Усиленный); у серверов из подписки — настройки панели.
- Базы geoip/geosite не в APK: скачиваются с GitHub (SHA256), когда их требует сервер или профиль.
- После включения ТВ клиент подключается сам, если VPN был включён.
- Ядро обновляется вместе с программой (отдельного обновления ядер нет).

## Добавить с телефона
«Серверы → Добавить» (или «Настройки → Добавить с телефона») показывает QR-код страницы в домашней сети. На ней
вставляется ссылка подписки, ссылки серверов, `cupoftea://…`, профиль маршрутизации или свой DNS-over-HTTPS — ТВ
получает их сразу. Там же — файл диагностики без ключей и адресов. Страница работает, пока открыт экран (до 10 минут),
адрес содержит одноразовый ключ, отвечает только адресам локальной сети.

## Обновления
Через 15 с после запуска и каждые 3 часа программа смотрит релизы репозитория: самый новый с тегом `tv-v<версия>` и
файлом `CupOfTea-TV-<версия>-<abi>.apk`. SHA256 берётся из `digest` GitHub (без него не ставит). Плашка на «Главной»,
уведомление — один раз на версию; установка — системным установщиком Android (он спросит подтверждение; на Android 8+
нужно разрешение «Установка неизвестных приложений» для The Cup of Tea).

## Сборка
Нужны JDK 21, Android SDK (platform 37, build-tools), NDK, Go и gomobile — версии закреплены в `core-go/go.mod`
и `gradle/libs.versions.toml`.
```powershell
scripts\build-core.ps1        # ядро xray → app\libs\libcup.aar (gomobile, три архитектуры)
.\gradlew.bat :core:test      # юнит-тесты логики
.\gradlew.bat :app:assembleDebug
scripts\new-release-key.ps1   # один раз: ключ подписи в %USERPROFILE%\.cupoftea (сделайте резервную копию!)
scripts\build-apk.ps1         # подписанные APK → ..\out\CupOfTea-TV-<версия>-<abi>.apk
scripts\make-banner.ps1       # перерисовать баннер и значок
```
Версия — `tvVersion` в `app/build.gradle.kts`. Ключ подписи хранится только у владельца: без него обновления поверх
установленной версии не встанут.

## Выпуск
Релиз ТВ не должен становиться «последним» в репозитории — десктоп берёт `releases/latest` и ждёт тег `x.y.z`:
```powershell
gh release create tv-v<версия> ..\out\CupOfTea-TV-<версия>-*.apk --repo MDFillin/cup-of-tea `
  --title "The Cup of Tea для Android TV <версия>" --notes-file <файл> --latest=false
```

## Установка на приставку
Скачайте APK под архитектуру приставки и откройте его файловым менеджером или браузером ТВ (разрешите установку из
неизвестных источников). При установке по adb указывайте установщик — иначе некоторые лаунчеры (например, у SberBox)
не покажут значок: `adb install -r -i com.android.packageinstaller <apk>`.
